# 🩺 Breast Cancer Prediction using Machine Learning

## 📌 Overview

This is my first Machine Learning project built to understand the complete ML workflow using the Breast Cancer Wisconsin dataset from Scikit-learn.

The objective of this project was not just to build a model but to learn the complete pipeline involved in a supervised machine learning classification problem.

---

## 🎯 Objective

Predict whether a breast tumor is:

- Malignant (Cancerous)
- Benign (Non-cancerous)

using 30 medical features extracted from tumor cell measurements.

---

## 📂 Dataset

- Dataset: Breast Cancer Wisconsin Dataset
- Source: Scikit-learn (`load_breast_cancer()`)

Dataset Information:

- Total Samples: 569
- Features: 30
- Target Classes:
  - 0 → Malignant
  - 1 → Benign

---

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn

---

## 📖 Machine Learning Pipeline

1. Import Libraries
2. Load Dataset
3. Convert Dataset into a Pandas DataFrame
4. Explore the Dataset
5. Create Features (`X`) and Target (`y`)
6. Train-Test Split
7. Train Logistic Regression Model
8. Make Predictions
9. Evaluate Model Accuracy

---

## 📊 Model Used

- Logistic Regression

---

Model Accuracy:

95.61%
